# 📖 AI学学乐

面向 **中小学生**的现代互动自学应用（家庭本地部署）。对标中小学课程标准：**606 节课 · 15 个学科 · 覆盖小学到高中**，每课配「开场一问 + 课本式讲解 + 参数互动演示 + 随堂小练 + 错题闭环」。

> 核心理念：**专业精准的教学自学**。学习流程内没有 AI 对话插入——讲解像课本一样自己能读懂、演示像实验一样自己能动手；AI 只住在独立的「问老师」答疑页，卡住了再去问。

## 课程形态（三层）

| 形态 |节数| 说明 |
|------|----|------|
| 🎛 互动卡片实验室 | 186 | 原生设计卡片：渐变标题 + 信息卡/对照卡/步骤卡/金句卡，左侧滑块切换场景（如历史事件四维度、英语句型三场景） |
| 📈 SVG 动态图表实验室 | ~360 | 拖参数实时重绘的动态演示（PhET 式）：函数图像、递归同心圆、能量金字塔、时区地球仪……自动构图 + 五色主题纪律渲染 |
| 📚 课本阅读页 | ~60 | 无代码课的阅读形态：开场一问 + 教材正文 + 思维导图 + 笔记 + 跨学科链接 |

学科覆盖：数学 103 · 语文 60 · 英语 49 · 物理 44 · 地理 39 · 化学 37 · 科学 36 · **历史 36（史前→当代→世界史，中考纲全覆盖）** · 生物 35 · 信息科技 34 · 道德与法治 31 · 音乐 29 · 艺术 25 · 劳动 24 · 体育与健康 24。

## 学习闭环（学而思/猿辅导式）

```
① 预习（开场一问）→ ② 学习（讲解+拖滑块做实验+想一想问题）→ ③ 小练（随堂选择题）→ ④ 巩固（错题本消灭）
```

- **课堂报告卡**：小练完成自动弹出——得分环 + 知识点清单 + 学习路径四步 + 老师评语，可随时回看
- **错题本闭环**：答错自动收录 → 重练全对移出 → 同考点「举一反三」推荐 → 错次排行 → 可打印纸质重练卷
- **间隔复习**：完成于 1/3/7/14 天前的课进入「复习黄金期」
- **期末模拟卷**：全学科抽 20 题限时组卷，按课标模块诊断薄弱点；**期末复习计划**按模块掌握度排 N 天计划

## 快速开始

需要 Node.js 18+（开发用 24 验证通过）。

```bat
:: 双击即可（首次自动安装依赖、构建、生成配置）
start.bat
```

浏览器打开 **http://127.0.0.1:8787**。

### 启用答疑页的 AI（可选）

不配置也能完整学习（AI 以离线替身模式回复）。要接真模型：

1. 编辑 `data/config.json`，填入任意 OpenAI 兼容接口的 `apiKey`（默认模板智谱 GLM；DeepSeek 把 `baseURL` 换成 `https://api.deepseek.com`、`model` 换成 `deepseek-chat`）
2. 重启 `start.bat`

key 只存本机（`data/` 已 gitignore，永不入库）。

### 平板在同一 WiFi 使用

`data/config.json` 里 `server.host` 改成 `"0.0.0.0"`，重启后用电脑局域网 IP 访问（`ipconfig` 查 IPv4）。

### 开发模式

```bat
start-dev.bat   :: server(8787 热重载) + vite(5173 热更新)
```

测试：`npm test`（186 个单元测试：推荐引擎/挑战抽样/口算/诗词/配平/解方程/分享卡等）。

## 怎么加一节课

复制一份相近形态的课程 JSON 修改（生成脚本见 `scripts/gen-*.mjs` 可参考）：

- `order` 排序 · `subjectArea` 学科 · `gradeBand`/`grade` 学段年级 · `textbook` 教材
- `story` 开场一问 · `goals` 学习目标 · `curriculum` 课标标注
- `teach.sections/examples/mistakes` 讲解三件套（正文/例题拆解/易错警示）
- `exercises` 选择题（≥3 题，答案位置请错开——审计会查分布）
- `lab.params` 滑块参数 + `interact.views` 卡片视图（或 `lab.code` SVG 演示代码）
- `interact.explore` 探索问题（想一想栏）

保存后刷新页面即生效；跑 `npx tsx scripts/audit-interact.mjs` / `audit-exercises.mjs` 自检。

## 隐私与儿童安全

- 所有数据（进度、作品、对话、样本）仅在本机，不上云
- 孩子输入含手机号/住址等个人信息时不转发给大模型；模型输出自动剥除链接
- 答疑对话全量落盘，家长面板按日期可查
- 无社交、无广告、无内购
