# 📖 AI学学乐

面向 **中小学生**的现代互动自学应用（家庭本地部署）。对标中小学课程标准：**670 节课 · 18 个学科 · 3905 道题 · 覆盖小学到高中**，每课配「开场一问 + 课本式讲解 + 参数互动演示 + 随堂小练（选择+填空）+ 错题闭环」。

> 核心理念：**专业精准的教学自学**。学习流程内没有 AI 对话插入——讲解像课本一样自己能读懂、演示像实验一样自己能动手；AI 只住在独立的「问老师」答疑页，卡住了再去问。

## 学习闭环（学而思/猿辅导式）

```
① 预习（开场一问）→ ② 学习（讲解+拖滑块做实验+想一想问题）→ ③ 小练（选择+填空双题型）→ ④ 巩固（错题本消灭）
```

- **课堂报告卡**：小练完成自动弹出——得分环 + 知识点清单 + 学习路径四步 + 老师评语 + **⭐获得学习之星** + **🧭难度自适应下一站**（高分推更深/低分补基础），可随时回看
- **错题本闭环**：答错自动收录 → **到期优先重练**（错次多+时间久的先练，Anki 式）→ 重练全对移出 → 同考点「举一反三」→ 可打印纸质重练卷
- **间隔复习**：完成于 1/3/7/14 天前的课进入「复习黄金期」
- **期末模拟卷**：全学科抽 20 题限时组卷 · **由易到难排卷** · 按课标模块诊断薄弱点

## 激励体系（多邻国式）

**学习之星（XP）+ 等级**：小练完成发放（每对 10 星 + 全对 20 + 完成 5），七档称号从「见习学员」到「传奇学霸」。四场景全覆盖：课堂报告（⭐本课获得）→ Header（⭐LV 徽章）→ 学科页单元头（满星约 N⭐ 预估）→ 家长端（等级卡+进度条）。

**今日学习大 CTA**：地图页顶部渐变大卡——推荐课 + 🔥连续天数 + 年级个性化理由 + 一键直达。

## 年级个性化（全程贯穿）

建档时选年级（1-12，家长端可改）→ 学科页同年级课打「⭐ 我的年级」标并**置顶排序** → 首页推荐优先推**同龄新课** → 期末卷与挑战赛**同龄题优先入卷**。

## 题库质量

- **双题型**：选择题（词卡 2×2 点选 / ABCD 列表自适应）+ **真填空题**（词库点选 / 键盘输入，题干挖空呈现，填空判分忽略大小写+trim）
- **答题体验**：音效反馈（正确叮咚/错误低音，WebAudio 本地合成）· 连击计数（≥3 显示🔥×N）· 读题按钮
- **智能排序**：由易到难排卷（题目难度三级启发式）· 错题到期优先（Anki 式间隔）
- **六套自动审计**全绿：SVG 舞台体检 / 卡片课八项 / 题库五项（答案均衡·无重复·无空解析）/ 泄漏检测（题干不含答案/干扰项等长）/ schema 校验 / 实验代码全量解析

## 怎么加一节课

复制相近形态的课程 JSON 修改（生成脚本见 `scripts/gen-*.mjs`）：

- `order` 排序 · `subjectArea` 学科 · `gradeBand`/`grade` 学段年级
- `story` 开场一问 · `goals` 目标 · `curriculum` 课标标注
- `teach` 讲解（正文/例题/易错）· `exercises` 题（≥3 题，答案位置错开，可加 `type:'blank'` 填空题）
- `lab.params` + `interact.views` 卡片视图（或 `lab.code` SVG 演示代码）· `interact.explore` 探索问题

保存后刷新页面即生效。
